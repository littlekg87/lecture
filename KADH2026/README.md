# KADH 2026 발표자료

**역사학 RAG에서의 파인튜닝 임베딩 문제 — 조선왕조실록 사례를 중심으로**

*Fine-Tuned Embeddings in Historical RAG: A Case Study of the Veritable Records of the Chosŏn Dynasty*

발표자 김근하 · 국립부경대학교 해양인문학연구소

실록의 현대어 제목과 한문 본문을 짝지어 임베딩 모델을 학습하고, 검색 성능을 두 방식으로 평가했다. 벤치마크에서는 세 규모의 기본·파인튜닝 모델 6종을 비교했고, 전문가 평가에서는 그중 4종이 찾아낸 사료의 관련성을 역사연구자가 평정했다.
