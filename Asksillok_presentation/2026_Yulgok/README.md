통합 관리 위치: `Asksillok_presentation/2026_Yulgok/`. 상위의 [Ask Sillok 발표 목록](../README.md)에서 다른 행사판을 볼 수 있습니다. 기존 발표 주소와 QR은 새 위치로 연결됩니다.
