## 자료 내려받기

깃허브 사용법을 몰라도 됩니다.

1. 이 페이지 위쪽의 초록색 **`< > Code`** 버튼을 누릅니다.
2. 맨 아래 **`Download ZIP`** 을 누릅니다.
3. 압축을 풀고, 수강 중인 강의 폴더로 들어갑니다.

각 강의 폴더 안의 `README.md` 에 자세한 실습 안내가 들어 있습니다.
