# 통계 분석 실습 데이터 (3-2차시)

『세종실록』 지리지의 **호(戶)·구(口)·군사 데이터**를 군현 단위로 정리한 자료입니다.
호·구·군정 사이의 상관관계를 분석해, **인구와 군역 부담이 공평했는지** 확인하는 데 씁니다.

## 파일

| 파일 | 설명 |
|---|---|
| `population-military.xlsx` | 원본 엑셀 파일 |
| `population-military-counties.csv` | 위와 같은 내용의 CSV **(UTF-8, 맥에서도 한글이 깨지지 않음)** |
| `jeolla-scatter-example.png` | 결과 예시 — 전라도의 호·수군 산점도 |

> 엑셀과 CSV **아무거나 불러오면 됩니다.** 내용은 같습니다.
> 맥에서 한글이 깨지는 일이 있으면 **CSV** 를 쓰세요.

## 열 구성

**333개 군현**, 11개 열입니다.

| 열 이름 | 설명 |
|---|---|
| `연번` | 원자료의 일련번호 |
| `도` | 팔도 (경기·충청도·경상도·전라도·황해도·강원도·평안도·함길도) |
| `고을` | 목·부·도호부 등 |
| `하위고을` | 위 고을에 딸린 군현 |
| `고을_한글_세부` | 본부·본주·본군·본현 등 구분 |
| **`戶 아라비아`** | **호(戶) 수 — 가구 수** |
| **`口 아라비아`** | **구(口) 수 — 인구 수** |
| `번상군` | 番上軍 — 서울로 번을 서러 올라가는 군사 |
| `유방군` | 留防軍 — 지방에 머물며 방어하는 군사 |
| `수군` | 水軍 — 수상 방어 군사 |
| **`군정수`** | **군정(軍丁) 총수 = 번상군 + 유방군 + 수군** |

강의에서는 굵게 표시한 **`戶 아라비아`, `口 아라비아`, `군정수`** 세 열로 상관관계를 분석합니다.

## 확인된 분석 결과

이 데이터로 피어슨 상관계수를 구하면 **교안의 표와 똑같은 값**이 나옵니다.

| | 戶 ~ 口 | 戶 ~ 군정수 | 口 ~ 군정수 |
|---|---|---|---|
| Pearson's r | **0.733** | **0.895** | **0.718** |
| df | 331 | 331 | 331 |
| p-value | < .001 | < .001 | < .001 |

세 값 모두 1에 가깝습니다. 곧 **호가 늘면 구도 늘고, 구가 늘면 군정도 느는 관계**가
뚜렷하다는 뜻이며, 조선 전기의 군역 부과가 인구 규모를 따라 이루어졌음을 보여 줍니다.

> 위 표와 다른 값이 나온다면, 세 열을 제대로 골랐는지 다시 확인해 보세요.
> `df` 가 331이 아니라면 일부 행이 빠졌거나 더해진 것입니다.

## 원본에서 손본 부분

| 무엇을 | 왜 |
|---|---|
| 셀 앞뒤 공백 제거 (`'경기 '` → `'경기'`) | 통계 프로그램이 `경기` 와 `경기 ` 를 **다른 항목으로 취급**하기 때문 |
| 이름 없던 3·4번째 열에 `고을`·`하위고을` 이름 부여 | 이름이 없어 프로그램이 `C`, `D` 로 자동 명명하던 것을 정리 |
| CSV를 UTF-8로 저장 | 맥에서 한글이 깨지지 않게 |

> `戶 아라비아`, `口 아라비아`, `군정수` 세 열의 **이름과 값은 원본 그대로 두었습니다.**
> 강의 영상의 결과표와 똑같이 나오도록 하기 위해서입니다.

## 주의

- `연번` 은 **1부터 순서대로 이어지지 않습니다.** (13, 14, … 22, 27, 36 …)
  더 큰 원자료에서 뽑아온 번호이기 때문이며, 분석에는 쓰지 않습니다.
- `하위고을` 과 `고을_한글_세부` 는 **비어 있는 칸이 많습니다.** 정상입니다.
