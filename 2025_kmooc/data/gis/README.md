# ⛔ 공간데이터 이용 제한 — 반드시 먼저 읽어 주세요

## 이 폴더의 지도 파일은 자유롭게 쓸 수 있는 자료가 아닙니다

```
adm_do.shp   adm_do.shx   adm_do.dbf
adm_do.prj   adm_do.cpg   adm_do.qmd
```

위 **조선 팔도 경계 셰이프파일**은
**한국학중앙연구원 김현종 교수님께서 본 강의를 위해 특별히 제공해 주신 자료**입니다.

---

## 지켜 주셔야 할 것

### ✅ 허용되는 것

- **본 강의의 실습 목적으로만** 사용

### ⛔ 금지되는 것

- 강의 수강생이 아닌 **제3자에게 전달·공유**하는 행위
- 블로그·SNS·다른 저장소 등 **외부에 재배포·업로드**하는 행위
- 논문·보고서·용역·상업적 결과물 등 **강의 외 목적으로 사용**하는 행위
- 가공·편집한 파생 데이터를 **위 목적으로 사용하거나 배포**하는 행위

> ### 🔴 무단 유출 또는 무단 사용은 저작권 이용 원칙에 위배됩니다.
> 이 자료는 제공자의 호의로 강의에 한해 이용이 허락된 것입니다.
> **실습이 끝난 뒤에는 개인적으로 보관하지 마시고 삭제해 주시기 바랍니다.**

**강의 외의 용도로 이 데이터를 사용하고자 하는 경우, 반드시 사전에
담당 교수를 통해 제공자의 별도 허락을 받으셔야 합니다.**

## 함께 있는 다른 파일

| 파일 | 내용 | 이용 제한 |
|---|---|---|
| `adm_do.*` (6개) | 조선 팔도 경계 지도 | **위 제한이 적용됩니다** |
| `provinces-data.csv` | 팔도별 호수·인구수·군사 수 통계 | 『세종실록』 지리지에서 정리한 자료 |

`provinces-data.csv` 는 『세종실록』 지리지(국사편찬위원회 조선왕조실록 DB)에서
정리한 통계 자료로, 위 지도 파일과는 출처가 다릅니다.
