# QGIS 설치 및 사용 가이드 (2026년 최신판)

> **이 문서를 먼저 읽어야 하는 이유**
> 강의 영상은 **QGIS 3.38 (Grenoble)** 화면으로 촬영되었습니다.
> 지금 QGIS 공식 사이트에 가면 **4.2 버전**이 먼저 보이는데,
> **4.x는 큰 폭으로 바뀐 버전이라 영상과 화면이 많이 다릅니다.**
>
> ### 👉 **이 강의에서는 반드시 LTR(장기 지원) 버전인 `3.44` 를 받으세요.**

## 1. 어떤 버전을 받아야 하나

QGIS는 늘 **두 갈래**로 배포됩니다.

| 종류 | 현재 버전 | 성격 | 이 강의에서는 |
|---|---|---|---|
| **LTR (장기 지원)** | **3.44 `Solothurn`** | 안정성 우선. 오래 유지됨 | ✅ **이걸 받으세요** |
| Regular (최신) | 4.2 `Belém do Pará` | 새 기능 우선. 화면이 많이 바뀜 | ❌ 권장하지 않음 |

- 강의 영상은 3.38에서 찍었고, **3.44는 3.38과 화면이 거의 같습니다.**
- 4.2는 메뉴 구조와 아이콘이 크게 달라져 영상을 따라가기 어렵습니다.
- QGIS 공식 사이트도 *"어느 것이 좋을지 모르겠으면 LTR을 받으라"* 고 안내합니다.

> 이미 4.x를 설치하셨더라도 괜찮습니다. **기능은 모두 있습니다.**
> 다만 메뉴 위치가 달라 영상과 대조하기 번거로울 뿐입니다.

## 2. 설치하기

내려받는 곳: **https://qgis.org/download/**

### Windows

페이지에서 **"Long Term Version for Windows (3.44 LTR)"** 를 찾아 누릅니다.

두 가지 방식이 있는데, **처음이라면 아래쪽을 고르세요.**

| 방식 | 설명 |
|---|---|
| OSGeo4W Network Installer | 여러 버전을 함께 쓰거나 부분 설치할 때. **복잡합니다.** |
| **Standalone Installer** | ✅ **한 번에 다 설치되는 방식. 이걸 고르세요.** |

1. 내려받은 `.msi` 파일을 더블클릭합니다.
2. "Windows의 PC 보호" 창이 뜨면 → **추가 정보** → **실행**.
3. 다음 → 동의 → 설치. (용량이 커서 5~10분 걸립니다.)

### macOS

페이지에서 **"Long Term Version for macOS (3.44 LTR)"** 를 눌러 `.dmg` 를 내려받습니다.

1. `.dmg` 를 더블클릭합니다.
2. **QGIS 아이콘을 Applications 폴더로 끌어다 놓습니다.**
3. **응용 프로그램** 폴더에서 QGIS를 실행합니다.

> 💡 **좋은 소식** — QGIS 맥용 설치 파일은 애플의 **정식 서명·공증(notarized)** 을 받았습니다.
> Gephi와 달리 "손상된 파일" 같은 보안 경고가 **뜨지 않습니다.**
> 혹시 경고가 뜬다면 아이콘을 `control` 키를 누른 채 클릭 → **열기** 를 누르세요.

> ⚠️ 맥에서 QGIS는 첫 실행이 **1~2분** 걸릴 수 있습니다. 멈춘 게 아니니 기다려 주세요.

## 3. 실습 파일 살펴보기

실습 폴더: **`data/gis/`**

### (1) 지도 모양 파일 — 셰이프파일 (Shapefile)

```
adm_do.shp   ← 지도 모양 (이 파일을 QGIS에서 엽니다)
adm_do.shx   ← 위치 색인
adm_do.dbf   ← 속성표 (도 이름 등)
adm_do.prj   ← 좌표계 정보
adm_do.cpg   ← 글자 인코딩 정보 (UTF-8)
adm_do.qmd   ← QGIS 부가 정보
```

> 🔴 **매우 중요** — 셰이프파일은 **6개 파일이 한 세트**입니다.
> `adm_do.shp` 하나만 복사해 가면 **열리지 않습니다.**
> 옮길 때는 반드시 **`adm_do.` 로 시작하는 파일 전부**를 함께 옮기세요.

**이 지도에 들어 있는 것**

- 조선 팔도(八道)의 경계 — 경기도·충청도·경상도·전라도·황해도·강원도·평안도·함길도
- 여기에 **한성(漢城)** 이 하나 더 들어 있어 **총 9개 구역**입니다.
- 좌표계는 **WGS84 (EPSG:4326)** 입니다.
- 출처: 국사편찬위원회 역사지리정보DB (2024년판)

### (2) 통계 데이터 — CSV

`provinces-data.csv` — 『세종실록』 지리지의 팔도별 집계입니다.

| 연번 | 행정구역 | 호수 | 인구수 | 번상군 | 유방군 | 수군 | 군정수 |
|---|---|---|---|---|---|---|---|
| 1 | 경기도 | 20882 | 50352 | 1713 | 0 | 3892 | 5605 |
| 2 | 충청도 | 24170 | 100790 | 1974 | 2014 | 7858 | 11846 |
| … | … | | | | | | |

> 📌 **이 파일은 강의 초기 배포본에서 수정되었습니다.**
> 예전 파일은 ① 글자 인코딩이 옛날 방식이라 **맥에서 한글이 깨졌고**,
> ② 아래에 **빈 줄 400개와 `#REF!` 오류**가 붙어 있어 QGIS에서 지도가 이상하게 나왔습니다.
> 지금 파일은 두 문제 모두 고쳐진 **8줄짜리 UTF-8 파일**입니다.

## 4. 지도 만들기 (전체 순서)

목표: **팔도별 군정수(軍丁數)를 색 진하기로 표현한 지도** 만들기

### 1단계 — 지도 파일 열기

1. QGIS를 실행하고 **새 프로젝트**로 시작합니다.
2. 메뉴 **레이어 → 레이어 추가 → 벡터 레이어 추가…**
3. **벡터 데이터셋** 칸의 `…` 을 눌러 **`adm_do.shp`** 를 고릅니다.
4. **인코딩**이 **`UTF-8`** 인지 확인합니다. ← 한글이 깨지지 않게 하는 부분입니다.
5. **추가** → **닫기**.

> ✅ 조선 팔도 모양이 화면에 나타나면 성공입니다.
> 안 보이면 왼쪽 레이어 목록에서 `adm_do` 를 **오른쪽 클릭 → 레이어로 확대** 하세요.

### 2단계 — 속성표 확인하기

1. 왼쪽 레이어 목록의 `adm_do` 를 **오른쪽 클릭 → 속성 테이블 열기**.
2. 맨 오른쪽 **`도`** 열을 봅니다. 여기에 도 이름이 들어 있습니다.
3. **9줄** 중 **한 줄(한성)은 `도` 칸이 비어 있습니다.** 정상입니다.

> 이 **`도`** 열이 뒤에서 CSV와 지도를 이어 주는 **열쇠(key)** 가 됩니다.

### 3단계 — CSV 불러오기

1. 메뉴 **레이어 → 레이어 추가 → 구분자로 나눠진 텍스트 레이어 추가…**
2. **파일 이름** 에서 `provinces-data.csv` 를 고릅니다.
3. 아래 항목을 확인합니다.

   | 항목 | 이렇게 맞추세요 |
   |---|---|
   | 파일 형식 | **CSV (쉼표로 구분된 값)** |
   | 인코딩 | **UTF-8** |
   | 도형 정의 | **도형 없음 (속성 전용 테이블)** ← 중요합니다 |

4. **추가** → **닫기**.

> 이 CSV에는 좌표가 없고 숫자만 있으므로 **"도형 없음"** 을 골라야 합니다.
> 지도에는 아무것도 안 그려지고, 레이어 목록에만 표가 추가되면 정상입니다.

### 4단계 — 지도와 데이터 잇기 (조인)

1. `adm_do` 를 **오른쪽 클릭 → 속성 → 조인(Joins)** 탭.
2. 왼쪽 아래 **`+`** 를 누릅니다.
3. 아래처럼 맞춥니다.

   | 항목 | 값 |
   |---|---|
   | 레이어 조인 | `provinces-data` |
   | **조인 필드** | **`행정구역`** ← CSV 쪽 열쇠 |
   | **대상 필드** | **`도`** ← 지도 쪽 열쇠 |

4. **확인** → **확인**.

> ✅ 속성 테이블을 다시 열어 **`provinces-data_군정수`** 같은 열이 새로 생겼으면 성공입니다.
> **한성 줄만 비어(NULL) 있는 것이 정상입니다.** CSV에 한성 자료가 없기 때문입니다.

### 5단계 — 색칠하기 (단계구분도)

1. `adm_do` 를 **오른쪽 클릭 → 속성 → 심볼(Symbology)** 탭.
2. 맨 위 드롭다운을 **`단일 심볼`** 에서 **`단계 구분(Graduated)`** 로 바꿉니다.
3. 아래처럼 설정합니다.

   | 항목 | 값 |
   |---|---|
   | 값 | `provinces-data_군정수` |
   | 색상 램프 | 아무거나 (예: Reds, Blues) |
   | 모드 | `동일 개수 (Quantile)` 또는 `자연 분류 (Jenks)` |
   | 클래스 | `5` |

4. **분류(Classify)** 버튼을 **꼭 누릅니다.** (이걸 안 눌러 색이 안 나오는 경우가 가장 많습니다.)
5. **확인**.

> ✅ 군정수가 많은 도일수록 진한 색으로 칠해집니다.
> **한성만 회색(또는 무색)으로 남는데, 자료가 없어서 그런 것이니 정상입니다.**

### 6단계 — 도 이름 표시하기

1. `adm_do` **오른쪽 클릭 → 속성 → 라벨(Labels)** 탭.
2. 맨 위를 **`단일 라벨`** 로 바꿉니다.
3. **값**을 **`도`** 로 고릅니다.
4. 글꼴 크기를 적당히(10~12) 맞추고 **확인**.

> 한글이 네모(□□□)로 나오면 **글꼴**을 `맑은 고딕`(윈도우) 또는 `AppleGothic`(맥)으로 바꾸세요.

### 7단계 — 그림으로 내보내기

1. 메뉴 **프로젝트 → 가져오기/내보내기 → 지도를 이미지로 내보내기…**
2. 해상도를 **300 dpi** 정도로 올리고 **저장**.

### 8단계 (선택) — 조인 결과를 파일로 저장하기

조인은 **QGIS를 닫으면 사라지는 임시 연결**입니다. 결과를 남기려면 저장해야 합니다.

1. `adm_do` **오른쪽 클릭 → 내보내기 → 객체를 다른 이름으로 저장…**
2. **형식**을 **`GeoPackage`** 로 고릅니다.
3. 파일 이름을 정하고 **확인**.

> ⚠️ **왜 셰이프파일이 아니라 GeoPackage인가요?**
> 셰이프파일은 **열 이름이 10글자를 넘으면 잘립니다.**
> `provinces-data_군정수` 같은 긴 이름이 `provinces_` 처럼 잘려 알아볼 수 없게 됩니다.
> GeoPackage는 이런 제한이 없고, 파일도 **하나로** 관리돼 훨씬 편합니다.

## 5. 문제가 생겼을 때

### 한글이 `???` 나 `���` 로 깨져 보여요

레이어를 추가할 때 **인코딩을 `UTF-8`** 로 지정하지 않은 경우입니다.

- 이미 추가한 레이어라면 → **오른쪽 클릭 → 속성 → 소스** 탭에서 인코딩을 `UTF-8` 로 바꿉니다.
- 그래도 안 되면 레이어를 지우고 **1단계부터** 다시 하세요.

### 지도가 안 보여요 / 화면이 텅 비었어요

레이어 목록에서 해당 레이어를 **오른쪽 클릭 → 레이어로 확대**를 누르세요.
그래도 안 보이면 레이어 이름 왼쪽의 **체크박스가 꺼져 있는지** 확인하세요.

### 조인했는데 새 열이 전부 비어 있어요(NULL)

**열쇠 값이 서로 다른** 경우입니다. 가장 흔한 원인 두 가지:

1. **조인 필드와 대상 필드를 반대로** 골랐습니다. → `행정구역` ↔ `도` 인지 다시 확인하세요.
2. 글자에 **눈에 안 보이는 공백**이 있습니다. → 배포된 파일은 공백을 미리 제거해 두었습니다.
   직접 만든 CSV를 쓴다면 `경기도 ` 처럼 뒤에 공백이 붙지 않았는지 확인하세요.

### 색이 하나도 안 칠해져요

**심볼 탭에서 `분류(Classify)` 버튼을 누르지 않았습니다.** 5단계 4번을 확인하세요.

### 셰이프파일이 안 열려요

`adm_do.shp` 만 따로 옮기지 않았는지 확인하세요.
**`.shp .shx .dbf .prj .cpg` 5개 파일이 같은 폴더에** 있어야 합니다.

### QGIS 4.x를 설치했는데 영상과 화면이 너무 달라요

기능은 모두 그대로 있지만 메뉴 위치가 다릅니다.
**3.44 LTR을 따로 설치하시길 권합니다.** 두 버전을 동시에 설치해도 서로 충돌하지 않습니다.
