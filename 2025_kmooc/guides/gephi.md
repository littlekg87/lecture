## 1. 무엇이 달라졌나

Gephi는 **0.10.1(2023년 1월)** 이후 3년 넘게 조용하다가 **0.11.1(2026년 5월)** 로 크게 바뀌었습니다.
현재 최신은 **0.11.2 (2026년 5월 9일)** 입니다.

| | 강의 영상 (0.10.1) | 최신 (0.11.2) |
|---|---|---|
| **아이콘** | 옛날 비트맵 아이콘 | **전부 새로 그린 SVG 아이콘** |
| **화면 그리는 방식** | 구형 엔진 | OpenGL 엔진을 처음부터 재작성 (더 빠름) |
| **한국어 메뉴** | 파일·보기·도구·창·도움말 **정도만** 한국어 | **Gephi 자체 한국어 번역 추가** |
| **노드에 마우스를 올리면** | 반응 없음 | 선택·편집 패널이 바로 뜸 |
| **이름표(라벨) 겹침** | 서로 겹쳐서 안 보임 | **겹침 방지 기능 추가** |
| **레이아웃 패널** | 배치만 | 회전·확대 등 변형 기능 추가 |
| **맥 애플실리콘** | Intel용으로 잘못 표시되는 버그 | 전용 빌드 제공 (정상) |

> **정리하면** — 버튼의 *생김새*와 *위치*가 달라졌을 뿐입니다.
> 영상에서 찾던 아이콘이 안 보이면 **같은 이름의 메뉴를 상단 메뉴바에서** 찾으세요.

### 한국어 메뉴에 대하여

영상 화면에도 `파일(F)`, `보기(V)`, `도구(T)` 같은 한국어 메뉴가 보입니다.
그건 Gephi가 올라타 있는 **바탕 프로그램(NetBeans)이 원래 갖고 있던 번역**이고,
**Appearance·Layout·Statistics 같은 Gephi 본체 화면은 전부 영어**였습니다.

**0.11.1부터 Gephi 본체에도 한국어 번역이 들어왔습니다.**
바꾸려면 **도구(Tools) → Language → 한국어** 를 고르면 됩니다. Gephi가 자동으로 재시작합니다.

> ⚠️ **다만 실습 중에는 영어로 두시길 권합니다.**
> 이 문서와 강의 영상이 모두 영어 화면 기준이라, 한국어로 바꾸면 오히려 헷갈립니다.
> 번역은 자원봉사로 이뤄져 일부 항목은 아직 영어로 남아 있기도 합니다.

## 2. 설치하기

내려받는 곳: **https://gephi.org/**

### Windows

1. **Windows (64-bit)** 를 눌러 `gephi-0.11.2-windows-x64.exe` 를 내려받습니다.
2. 내려받은 파일을 더블클릭합니다.
3. "Windows의 PC 보호" 파란 창이 뜨면 → **추가 정보** → **실행**.
4. 다음 → 다음 → 설치.

> ⚠️ 설치 중 **"Install for me only"(나만 사용)** 는 고르지 마세요. 오류를 일으킨 전력이 있습니다.

### macOS — **내 맥이 어떤 종류인지 먼저 확인하세요**

맥은 칩 종류에 따라 **받아야 할 파일이 다릅니다.** 잘못 받으면 느리거나 실행되지 않습니다.

**확인 방법** — 화면 왼쪽 위 **애플 로고 ()** → **이 Mac에 관하여**

| 거기에 이렇게 쓰여 있으면 | 내려받을 파일 |
|---|---|
| **칩: Apple M1 / M2 / M3 / M4 …** | `gephi-0.11.2-macos-`**`aarch64`**`.dmg` |
| **프로세서: Intel Core …** | `gephi-0.11.2-macos-`**`x64`**`.dmg` |

**설치 순서**

1. 위 표에 맞는 `.dmg` 를 내려받아 더블클릭합니다.
2. 창 안의 **Gephi 아이콘을 오른쪽 Applications 폴더 위로 끌어다 놓습니다.**
   (0.11.2부터 이 안내 화면이 새로 생겼습니다.)
3. **응용 프로그램** 폴더에서 Gephi를 실행합니다.
4. "확인되지 않은 개발자" 경고가 뜨면 → 아이콘을 **`control` 키를 누른 채 클릭 → 열기**.

> 💡 Gephi는 자바(Java)로 만들어졌지만 **자바를 따로 설치할 필요가 없습니다.**
> 설치 파일 안에 들어 있습니다.

## 3. 1단계 — 데이터 전처리

### 네트워크 데이터의 핵심

네트워크 분석을 하려면 **노드 · 엣지 · 가중치 · 방향성** 을 표로 만들어야 합니다.
보통 **`source`, `target`, `weight`** 세 열을 기본으로 넣고, 자료 성격에 따라 열을 더합니다.

| 열 이름 | 뜻 | 이 실습에서는 |
|---|---|---|
| `source` | 관계의 출발점 | 비변사 관원 A |
| `target` | 관계의 도착점 | 비변사 관원 B |
| `weight` | 관계의 세기 | 함께 재직한 횟수 |

### 실습 파일

**`data/network/bibyeonsa-network.csv`** — 19세기 비변사 관원 **25명**의 관계 **80줄**

> 📌 **교안·영상에서는 이 파일을 `실습예제_비변사 네트워크.csv` 라고 부릅니다.**
> 파일 이름만 영문으로 바꾸었을 뿐 **내용은 똑같습니다.**
> 한글과 띄어쓰기가 들어간 이름이 맥에서 오류를 일으키는 일이 있어 정리했습니다.

```
source,target,weight
이경재,이규철,6
이규철,이경순,3
김좌근,서대순,2
김대근,서대순,13
```

> 📌 예제 데이터의 내용은 **실습을 위해 임의로 구성한 것**입니다.

> 📌 **파일이 한 군데 수정되었습니다.**
> 예전 파일에는 맨 앞에 눈에 보이지 않는 표시(BOM)가 붙어 있어,
> Gephi가 첫 열 이름을 `source` 가 아닌 이상한 글자로 읽는 경우가 있었습니다. 제거했습니다.

## 4. 2단계 — Gephi에 데이터 입력

### 불러오기

1. Gephi를 실행하고 시작 화면에서 **`New Project`** 를 클릭합니다.
2. **좌측 상단의 `Data Laboratory` 탭**을 클릭합니다.
3. **중앙 상단의 `Import Spreadsheet`** 를 클릭합니다.

   > 🔸 **0.11.2에서 달라진 점** — 이 버튼의 아이콘 그림이 바뀌었습니다.
   > 그림 대신 **글자 `Import Spreadsheet`** 를 찾으세요. 위치는 그대로입니다.

4. **`bibyeonsa-network.csv`** 파일을 고릅니다.
5. **General CSV options (2중 1)** 창이 뜹니다. 아래 두 가지만 확인하고 **`다음(Next)`**.

   | 항목 | 확인할 값 |
   |---|---|
   | Separator | `Comma` (쉼표) |
   | **Charset** | **`UTF-8`** ← 한글 이름이 깨지지 않게 하는 부분 |
   | Import as | `Edges table` |

6. **Import settings (2중 2)** 창에서 그대로 **`마침(Finish)`**.
7. **Import report** 창에서 **`OK`**.

> ✅ **제대로 됐는지 확인하기**
> 화면 오른쪽 **Context** 칸에 이렇게 나와야 합니다.
>
> ```
> Nodes:  25
> Edges:  75
> Directed Graph
> ```
>
> **CSV는 80줄인데 왜 엣지가 75개인가요?**
> 똑같은 (출발→도착) 짝이 5쌍 들어 있어서, Gephi가 하나로 합치고 가중치를 더했기 때문입니다.
> **정상입니다.** 영상 화면과 같은 숫자입니다.

> 🔸 **`Directed Graph`(방향 있는 그래프)를 그대로 두세요.**
> 교안과 영상이 기본값인 Directed로 진행합니다. 바꾸면 엣지 수가 달라져 화면이 영상과 달라집니다.

### 이름표(라벨) 만들기

불러온 직후에는 점에 이름이 붙어 있지 않습니다. 사람 이름을 이름표로 옮겨 줍니다.

8. **Data Table** 의 **`Nodes`** 탭에서, **중앙 하단의 `Copy data to other column`** 을 클릭합니다.
9. **`Id`** 를 고른 뒤 → **`Label`** 을 선택 → **`Ok`**.

> ✅ `Label` 열에 `이경재`, `김좌근` 같은 이름이 채워지면 성공입니다.

## 5. 3단계 — 네트워크 시각화

**`Overview` 탭**으로 돌아가서 진행합니다.

### (1) 보기 좋게 펼치기 — 레이아웃

1. 화면 **왼쪽 아래 `Layout`** 칸의 **`---Choose a layout`** 에서 **`Yifan Hu`** 를 고릅니다.
2. 아래 속성 목록에서 **`Optimal Distance`** 를 **`500.0`** 으로 바꿉니다.
3. **`Run`** 을 클릭합니다.

점들이 저절로 움직이며 자리를 잡고, 다 되면 알아서 멈춥니다.

> 💡 `Optimal Distance` 는 **점 사이를 얼마나 벌릴지** 정하는 값입니다.
> 너무 뭉쳐 보이면 더 크게(800, 1000), 너무 흩어지면 작게(300) 조절해 보세요.

> 🔸 **0.11.2에서 달라진 점** — 레이아웃 패널에 **회전·확대 같은 변형 기능**이 새로 생겼습니다.
> 교안에 없는 기능이니 지금은 무시하셔도 됩니다.

### (2) 중요한 사람을 크게 — 노드 크기

4. 화면 **왼쪽 위 `Appearance`** 칸에서 **`Nodes`** 를 고릅니다.
5. 오른쪽 위의 작은 아이콘 중 **`Size`(동그라미 두 개 겹친 모양)** 를 클릭합니다.
6. 그 아래 줄에서 **`Ranking`** 을 선택합니다.
7. 목록에서 **`Degree`**(연결 개수)를 고릅니다.
8. **`Min size`** 를 **`10`**, **`Max size`** 를 **`50`** 으로 입력합니다.
9. **`Apply`** 를 클릭합니다.

> ✅ 연결이 많은 사람일수록 점이 커집니다.
> 이 자료에서는 **서대순 · 김병기 · 임태영** 이 크게 나옵니다.

> 🔸 **0.11.2에서 달라진 점** — Appearance 칸의 아이콘이 전부 새 그림으로 바뀌었습니다.
> 아이콘 위에 마우스를 잠깐 올리면 `Size`, `Color` 같은 **이름이 뜹니다.** 그걸로 찾으세요.

### (3) 이름 보이게 하기 — 맥 사용자 필독

10. 화면 **아래쪽 도구 막대**에서 **`T`** 모양 버튼을 누릅니다. → 이름표가 나타납니다.
11. 그 오른쪽의 **글꼴 이름이 적힌 버튼**을 눌러 **한글 글꼴**로 바꿉니다.

| | 고를 글꼴 |
|---|---|
| **Windows** | `HY중고딕`, `맑은 고딕`, `굴림` 등 |
| **macOS** | **`AppleGothic`**, `Apple SD Gothic Neo`, `AppleMyungjo` |

> 🔴 **이 단계를 건너뛰면 이름이 `□□□` 네모로 나옵니다.**
> Gephi의 기본 글꼴(Arial)에는 한글이 없기 때문입니다.
>
> 🔴 **강의 영상은 `HY중고딕`을 쓰는데, 이 글꼴은 맥에 없습니다.**
> 맥 사용자는 목록에서 **`AppleGothic`** 을 고르세요. 결과는 똑같습니다.

12. 옆의 슬라이더로 글자 크기를 조절합니다. (영상은 32)

> 🔸 **0.11.2 신기능** — 이름표가 서로 겹쳐 안 보일 때,
> 시각화 설정에서 **글자 겹침 방지**를 켜면 자동으로 밀어내 줍니다. 영상보다 훨씬 깔끔합니다.

### (4) 그림으로 내보내기

13. 위쪽 **`Preview`** 탭으로 이동합니다.
14. 왼쪽 아래 **`Refresh`** 를 **반드시 누릅니다.**
    → 이걸 안 눌러 "화면이 하얗다"고 당황하는 경우가 가장 많습니다.
15. **`Export`** → `SVG` / `PDF` / `PNG` 로 저장합니다.

> 💡 Preview 탭에서도 **글꼴을 따로 지정해야** 합니다.
> 왼쪽 `Node Labels` → `Font` 에서 한글 글꼴을 다시 골라 주세요.

## 6. 더 해보기

교안 범위 밖이지만, 조금 더 해보고 싶은 분을 위한 내용입니다.

### 누가 중심인물인가 — 숫자로 확인하기

1. 오른쪽 **`Statistics`** 칸에서 **`Average Degree`** 옆 **`Run`**.
2. **`Data Laboratory`** 탭으로 가서 **`Degree`** 열을 봅니다.
   숫자가 클수록 많은 사람과 이어진 인물입니다.

### 무리 나누기 — 색으로 구분하기

1. **`Statistics`** → **`Modularity`** 옆 **`Run`**.
2. 창이 뜨면 **`Use weights`** 에 체크하고 **`OK`**.
3. **`Appearance`** → **`Nodes`** → **`Color`**(팔레트 아이콘) → **`Partition`**
   → 목록에서 **`Modularity Class`** → **`Apply`**.

무리별로 색이 다르게 칠해져, 어떤 사람들이 한 패였는지 눈으로 볼 수 있습니다.

## 7. 문제가 생겼을 때

### 이름이 `□□□` 네모로 나와요

**가장 흔한 문제입니다.** 글꼴이 한글을 지원하지 않아서입니다.
→ [5장 (3)번](#3-이름-보이게-하기--맥-사용자-필독) 으로 가서 한글 글꼴로 바꾸세요.
맥이라면 **`AppleGothic`** 입니다.

### 이름이 `???` 나 깨진 글자로 나와요

불러올 때 **Charset을 `UTF-8`** 로 지정하지 않은 경우입니다.
**File → New Project** 로 새로 시작해서 [4장](#4-2단계--gephi에-데이터-입력) 부터 다시 하세요.

### Nodes가 25개, Edges가 75개가 아니에요

- **Edges가 80** 이라면 → 중복 병합이 안 된 것입니다. 큰 문제는 아닙니다.
- **Edges가 69** 라면 → 그래프 유형이 `Undirected` 로 되어 있습니다. `Directed` 로 두세요.
- **Nodes가 25가 아니라면** → `Import as` 를 `Edges table` 이 아닌 다른 값으로 골랐을 수 있습니다.
  **File → New Project** 로 새로 시작하세요.

### 점이 화면에 안 보여요

아주 작게 몰려 있는 경우입니다.
화면 왼쪽 도구 막대의 **돋보기(Center on Graph)** 버튼을 누르면 중앙에 맞춰집니다.

### Preview 화면이 하얗게 비어 있어요

**`Refresh` 버튼을 누르지 않았습니다.** Preview 탭 왼쪽 아래에 있습니다.

### 맥에서 "손상되었기 때문에 열 수 없습니다"

1. **응용 프로그램** 폴더의 Gephi 아이콘을 **`control` 키를 누른 채 클릭 → 열기**.
2. 경고가 다시 떠도 **열기**. (한 번만 하면 다음부터는 그냥 열립니다.)
3. 그래도 안 되면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **그래도 열기**.

### "OpenGL을 지원하지 않는다"는 오류가 떠요

0.11부터 새 그래픽 엔진을 쓰기 때문입니다.

- 그래픽 드라이버를 최신으로 업데이트해 보세요.
- **원격 데스크톱·가상머신에서는 실행되지 않습니다.** 컴퓨터 앞에서 직접 실행하세요.

3. 최신 0.11.2는 **아이콘과 화면만 바뀌었을 뿐**, 순서와 결과는 영상과 같다.
