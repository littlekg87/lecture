# Gephi 설치 및 사용 가이드 (2026년 최신판)

> **이 문서를 먼저 읽어야 하는 이유**
> 강의 영상은 **Gephi 0.10.1** 화면으로 촬영되었습니다.

> 영상과 화면이 달라 보여도 당황하지 마세요. 기능과 순서는 그대로입니다.

## 1. 무엇이 달라졌나

Gephi는 **0.10.1(2023년 1월)** 이후 3년 넘게 조용하다가 **0.11.1(2026년 5월)** 로 크게 바뀌었습니다.
현재 최신은 **0.11.2 (2026년 5월 9일)** 입니다.

| 바뀐 것 | 강의 영상(0.10.1) | 최신(0.11.2) |
|---|---|---|
| **한국어 지원** | 없음 (영어만) | **한국어 메뉴 지원** |
| **아이콘** | 옛날 비트맵 아이콘 | 전부 새로 그린 SVG 아이콘 |
| **화면 그리는 방식** | 구형 엔진 | OpenGL 엔진을 처음부터 새로 작성 (더 빠름) |
| **노드에 마우스 올릴 때** | 반응 없음 | 선택·편집 패널이 바로 뜸 |
| **글자 겹침** | 라벨이 서로 겹침 | 겹침 방지 옵션 추가 |
| **레이아웃 패널** | 배치만 | 회전·확대 등 변형 기능 추가 |
| **맥 애플실리콘** | Intel용으로 잘못 표시되는 버그 | 전용 빌드 제공 (정상) |

> **정리하면** — 버튼의 *생김새*와 *위치*가 달라졌을 뿐, **누르는 순서와 결과는 영상과 같습니다.**
> 영상에서 찾던 아이콘이 안 보이면, 같은 이름의 메뉴를 상단 메뉴바에서 찾으세요.

## 2. 설치하기

내려받는 곳: **https://gephi.org/**

### Windows

1. 위 사이트에서 **Windows (64-bit)** 를 눌러 `gephi-0.11.2-windows-x64.exe` 를 내려받습니다.
2. 내려받은 파일을 **더블클릭**합니다.
3. "Windows의 PC 보호" 파란 창이 뜨면 → **추가 정보** → **실행** 을 누릅니다.
   (모르는 배포자라서 뜨는 경고일 뿐, 정상 프로그램입니다.)
4. 다음 → 다음 → 설치.

> ⚠️ 설치 중 **"Install for me only"(나만 사용)** 는 고르지 마세요.
> 예전 버전에서 이 옵션이 오류를 일으키는 문제가 있었습니다. 기본값 그대로 두세요.

### macOS — **내 맥이 어떤 종류인지 먼저 확인하세요**

맥은 칩 종류에 따라 **내려받을 파일이 다릅니다.** 잘못 받으면 느리거나 실행되지 않습니다.

**확인 방법**
> 화면 왼쪽 위 **애플 로고 ()** → **이 Mac에 관하여** 클릭

| 거기에 이렇게 쓰여 있으면 | 내려받을 파일 |
|---|---|
| **칩: Apple M1 / M2 / M3 / M4 …** | `gephi-0.11.2-macos-**aarch64**.dmg` |
| **프로세서: Intel Core …** | `gephi-0.11.2-macos-**x64**.dmg` |

**설치 순서**

1. 위 표에 맞는 `.dmg` 파일을 내려받습니다.
2. 내려받은 `.dmg` 를 **더블클릭**하면 창이 하나 열립니다.
3. 창 안의 **Gephi 아이콘을 오른쪽 Applications 폴더 아이콘 위로 끌어다 놓습니다.**
   (0.11.2부터 이 안내 화면이 새로 생겼습니다.)
4. **런치패드** 또는 **응용 프로그램** 폴더에서 Gephi를 실행합니다.

> 💡 Gephi는 자바(Java)로 만들어진 프로그램이지만,
> **자바를 따로 설치할 필요가 없습니다.** 설치 파일 안에 이미 들어 있습니다.

## 3. 한국어로 쓰기 (신기능)

**0.11.1부터 Gephi가 한국어를 지원합니다.** 영어 메뉴가 부담스러우면 바꿔 보세요.

1. 상단 메뉴에서 **Tools** → **Language** 를 엽니다.
2. 목록에서 **한국어 (Korean)** 를 고릅니다.
3. "언어가 바뀌었으니 다시 시작한다"는 안내가 뜹니다. **Gephi가 자동으로 재시작**됩니다.

> ⚠️ **다만 강의 영상은 영어 화면입니다.**
> 영상을 따라가는 동안에는 **영어(English)로 두는 편이 헷갈리지 않습니다.**
> 실습에 익숙해진 뒤 한국어로 바꾸시길 권합니다.
>
> 💡 번역은 자원봉사자들이 하고 있어서, 일부 항목은 아직 영어로 남아 있을 수 있습니다.

## 4. 실습 데이터 불러오기

실습 파일: **`data/network/bibyeonsa-network.csv`**
(19세기 비변사 관원 **25명**의 공동 재직 관계 **80건**)

파일을 열어 보면 이렇게 생겼습니다.

```
source,target,weight
이경재,이규철,6
이규철,이경순,3
김좌근,서대순,2
```

- `source` / `target` — 관계를 맺은 두 사람
- `weight` — 관계의 세기 (함께 재직한 횟수)

### 불러오는 순서

1. Gephi를 켜고 시작 화면에서 **New Project** 를 누릅니다.
2. 상단 메뉴 **File** → **Import spreadsheet…**
3. `bibyeonsa-network.csv` 를 고릅니다.
4. **불러오기 설정 창**이 뜹니다. 아래 세 가지를 꼭 확인하세요.

   | 항목 | 이렇게 맞추세요 |
   |---|---|
   | **Separator** | `Comma` (쉼표) |
   | **Import as** | **`Edges table`** ← 가장 중요합니다 |
   | **Charset** | `UTF-8` ← 한글 이름이 깨지지 않게 합니다 |

5. **Next >** 를 누릅니다.
   `source` → Source, `target` → Target, `weight` → Weight 로 알아서 연결됩니다.
   혹시 자동으로 안 잡히면, 목록에서 직접 골라 주세요.
6. **Finish** 를 누릅니다.
7. 마지막 창에서 **Graph Type** 을 **`Undirected`(무방향)** 로 바꿉니다.
   (누가 누구에게 준 관계가 아니라 '함께 있었다'는 관계이므로 방향이 없습니다.)
8. **OK**.

> ✅ 제대로 됐다면 화면 오른쪽 **Context** 칸에 **Nodes: 25 / Edges: 80** 이라고 나옵니다.
> 숫자가 다르면 4~7단계를 다시 확인하세요.

## 5. 네트워크 분석하기

### (1) 보기 좋게 펼치기 — 레이아웃

1. 왼쪽 아래 **Layout** 칸에서 **ForceAtlas 2** 를 고릅니다.
2. **Run** 을 누릅니다. 점들이 저절로 움직이며 자리를 잡습니다.
3. 어느 정도 자리가 잡히면 **Stop** 을 누릅니다.

> 💡 점들이 너무 뭉쳐 있으면 `Scaling` 값을 크게(예: 10 → 50), 너무 흩어지면 작게 조절하세요.
> `Prevent Overlap`(겹침 방지)에 체크하면 점들이 서로 포개지지 않습니다.

### (2) 누가 중심인물인가 — 연결 중심성

1. 오른쪽 **Statistics** 칸에서 **Average Degree** 옆의 **Run** 을 누릅니다.
2. 계산이 끝나면 **Data Laboratory** 탭으로 가서 `Degree` 열을 확인합니다.
   숫자가 클수록 많은 사람과 연결된 인물입니다.

### (3) 무리 나누기 — 모듈래리티

1. **Statistics** 칸에서 **Modularity** 옆 **Run** 을 누릅니다.
2. 창이 뜨면 **Use weights**(가중치 사용)에 체크하고 **OK**.
3. 왼쪽 위 **Appearance** 칸 → **Nodes** → **Partition** 선택
   → 목록에서 **Modularity Class** 를 고르고 → **Apply**.
4. 무리별로 색이 다르게 칠해집니다.

### (4) 이름 표시하기

- 화면 아래쪽 도구 막대의 **`T`** 모양 버튼을 누르면 이름이 나타납니다.
- 옆의 슬라이더로 글자 크기를 조절합니다.
- **0.11 신기능** — 시각화 설정에서 **글자 겹침 방지**를 켜면 이름이 서로 포개지지 않습니다.

### (5) 그림으로 내보내기

1. 위쪽 **Preview** 탭으로 이동합니다.
2. 왼쪽 아래 **Refresh** 를 눌러야 그림이 보입니다. (이걸 안 눌러 당황하는 경우가 많습니다.)
3. **Export → SVG/PDF/PNG…** 로 저장합니다.

## 6. 문제가 생겼을 때

### 한글 이름이 `???` 나 네모로 깨져 보여요

불러올 때 **Charset을 `UTF-8`** 로 지정하지 않은 경우입니다.
프로젝트를 닫고 **4장부터 다시** 하면서, 설정 창의 Charset을 확인하세요.

### 맥에서 "확인되지 않은 개발자" / "손상되었기 때문에 열 수 없습니다"

1. **응용 프로그램** 폴더에서 Gephi 아이콘을 찾습니다.
2. 아이콘을 **`control` 키를 누른 채 클릭** → 메뉴에서 **열기** 를 선택합니다.
3. 경고창이 다시 떠도 **열기** 를 누릅니다. (한 번만 하면 다음부터는 그냥 열립니다.)

그래도 안 되면 **시스템 설정 → 개인정보 보호 및 보안** 으로 가서,
아래쪽에 뜬 *"Gephi를 열 수 없습니다"* 옆의 **그래도 열기** 를 누르세요.

### 실행하면 "OpenGL을 지원하지 않는다"는 오류가 떠요

0.11부터 새 그래픽 엔진을 쓰기 때문에, 그래픽 드라이버가 오래됐거나
가상머신·원격 데스크톱 환경이면 이 오류가 납니다.

- 그래픽 드라이버를 최신으로 업데이트해 보세요.
- 원격 접속 중이라면, 컴퓨터 앞에서 직접 실행해 보세요.
- 그래도 안 되면 **[Google Colab으로 하는 실습](../notebooks/)** 처럼
  설치가 필요 없는 대안을 담당 조교에게 문의하세요.

### 불러왔는데 노드가 25개가 아니에요

**Import as** 를 `Edges table` 이 아니라 `Nodes table` 로 골랐을 가능성이 큽니다.
**File → New Project** 로 새로 시작해서 4장을 다시 따라 하세요.

### 점이 화면에 안 보여요

화면 어딘가에 아주 작게 몰려 있는 경우입니다.
화면 왼쪽 도구 막대의 **돋보기(Center on Graph)** 버튼을 누르면 화면 중앙에 맞춰집니다.
