# AI 시대의 역사 연구

**서강대학교 사학과 콜로키움 발표자료**

- 발표일: **2026.09.28.**
- 발표자: **김근하**

## 웹에서 보기

1. 위의 **발표자료 바로 보기** 링크를 엽니다.
2. 화면 아래의 **이전 단계 / 다음 단계** 버튼으로 진행합니다. 일부 장면은 같은 화면 안에서 설명 단계가 이어집니다.
3. 화면 위의 **전체 목차**에서 챕터와 장면을 선택할 수 있습니다.
4. 장면 안의 선택 버튼·도식·자료 항목을 눌러 설명과 변화를 살펴볼 수 있습니다. 추가 설명이나 출처는 해당 장면의 안내 버튼에서 확인합니다.

발표 화면은 데스크톱이나 노트북의 넓은 화면에서 보는 것을 권장합니다. 브라우저의 전체 화면 기능을 이용하면 발표에 집중하기 좋습니다.

## 내려받아 오프라인으로 보기

1. 이 폴더의 [`index.html`](index.html)을 열고 GitHub의 **Download raw file** 기능으로 저장합니다. 또는 저장소 첫 화면에서 **Code → Download ZIP**으로 전체 자료를 내려받습니다.
2. 저장한 `index.html`을 브라우저에서 엽니다.

발표 실행에 필요한 이미지·폰트·스크립트·데이터는 HTML 파일에 포함되어 있습니다. 별도 설치나 로컬 서버 없이 이용하도록 구성했습니다. Ask Sillok, 실록 원문 등 외부 사이트를 방문하려면 인터넷 연결이 필요합니다.
